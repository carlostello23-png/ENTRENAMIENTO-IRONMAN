# Archivo

Trabajo retirado. **Se guarda, no se borra.**

Aquí van planes reemplazados, semanas que se replantearon, protocolos que
dejaron de aplicarse y análisis que se descartaron.

Borrar un archivo viejo destruye la única forma de ver por qué se cambió de
idea. El historial de git ya guarda mucho, pero un documento retirado que
sigue siendo legible de un vistazo vale más que un `git log` que hay que
reconstruir.

Cuando algo se mueva aquí, se le añade arriba una línea con **la fecha y el
motivo** de la retirada.
